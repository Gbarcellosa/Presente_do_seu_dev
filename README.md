# Projeto pessoal — Presente do seu dev

## Visão geral

Este repositório é um projeto pessoal, voltado para uma apresentação visual e emocional. Ele foi construído como uma experiência dedicada a uma pessoa específica e não deve ser tratado como um projeto profissional principal no portfólio técnico.

## Objetivo

- criar uma página memorável e personalizada;
- celebrar uma história ou relacionamento pessoal;
- demonstrar criatividade em front-end e storytelling visual.

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript
- imagens locais
- arquivo de áudio em MP3

## Funcionalidades verificadas

- página com narrativa sequencial;
- uso de estilos personalizados;
- elementos visuais e animações;
- galeria de imagens;
- reprodução de música local;
- layout interativo e emocional.

## Status

É um projeto pessoal, com valor simbólico e visual, mas não o ideal como principal peça de apresentação profissional. No portfólio, ele deve aparecer como projeto pessoal e como uma expressão criativa, e não como trabalho técnico principal.

## Observação para portfólio

Para manter uma identidade profissional coerente, recomenda-se:

- manter este projeto em destaque apenas como projeto pessoal;
- não competir com projetos técnicos e profissionais;
- usar este repositório como material complementar, não principal.
